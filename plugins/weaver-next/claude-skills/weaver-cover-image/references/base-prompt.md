# Cover Image Design Principles

Create ONE cover/hero image.

## Specifications
- Style: hand-drawn illustration (no realistic/photographic elements).
- Aspect: 2.35:1 (article, default), 16:9, or 1:1 (social).

## Core principles
- Ample whitespace; highlight the core message; avoid clutter.
- Main visual centered or slightly left (leave the right for the title if included).
- One strong focal metaphor for the topic; a limited, deliberate palette.

## Text (when a title is included)
- ALL text hand-drawn, harmonized with the illustration style.
- Title large, eye-catching, <= 8 characters; optional one-line subtitle/keyword.
- Use the content's language and punctuation.
- Do NOT use realistic or computer-generated fonts.
