# Infographic Style Gallery

Each style = palette + elements + best-for. Pick by topic; default `data-report`.

## data-report
- **Palette:** deep navy `#0f1f33`, cyan accent `#1fa2dc`, cool greys, white.
- **Elements:** grid lines, mini bar/line charts, big figures, tidy tables.
- **Best for:** market sizing, financials, quantitative 赛道 overviews.

## editorial
- **Palette:** ink `#1a1a1a`, single warm accent (coral/amber), cream.
- **Elements:** strong headline typography, rule lines, pull quotes, restrained icons.
- **Best for:** thesis summaries, opinion, structured narratives.

## minimal-tech
- **Palette:** near-black, electric blue/violet accent, thin lines.
- **Elements:** geometric icons, lots of whitespace, one focal metric.
- **Best for:** technology/AI, product/architecture explainers.

## warm-brief
- **Palette:** terracotta, golden yellow, cream.
- **Elements:** rounded cards, friendly icons, soft dividers.
- **Best for:** consumer, education, human-interest briefs.
