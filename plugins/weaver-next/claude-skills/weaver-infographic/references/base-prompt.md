# Infographic Design Principles (investment-research tuned)

Compose ONE self-contained infographic that a busy analyst reads in 10 seconds.

## Core principles
- **One takeaway.** A single bold title states the conclusion; everything supports it.
- **Information hierarchy.** Title > section headings > insights > supporting detail. Size, weight, and color encode importance.
- **Sectioned grid.** 3–6 clearly separated blocks on a consistent grid with generous whitespace. Never a wall of text.
- **Data callouts.** Pull key numbers out as large figures with unit + source. Trends → arrows/mini-charts, shares → proportion bars/rings.
- **Restrained palette.** One base + one accent + neutrals. Color carries meaning (up/down, categories), not decoration.
- **Iconography.** Simple flat icons label sections; no photographic or 3D elements.
- **Traceability.** A small source line (机构/报告 · 时点) at the bottom. Investment figures must be citable.

## Text
- All text is rendered IN the image, in the content's language, exactly as written — no placeholder text, no garbled glyphs.
- Title <= 14 chars. Section headings <= 10 chars. Insights one line.
- When text is dense or numbers must be exact, render via SVG (crisper than an image model).

## Archetypes
- `vertical-sections`: stacked labeled sections (default, portrait).
- `comparison`: 2–3 columns side by side (options/companies).
- `timeline`: left→right stages with dates.
- `hub-and-spoke`: central concept, radiating factors.
- `funnel`: narrowing stages (market → segment → target).
